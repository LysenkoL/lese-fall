# Lese-Fall: Spur im Text

Детективная книга-приложение для самостоятельного чтения (немецкий, примерно 8+ лет, 2. Klasse). Продолжение приложения Leseraupe. Первая книга — **«Der verschwundene Mond»**: 4 главы, 24 сцены, после каждой — игра по тексту.

**Этот репозиторий — единственный источник правды.** Если документ от любого ИИ противоречит файлам здесь, то прав репозиторий. Новые версии документов кладутся сюда, а не пересылаются по чатам.

## Не использовать как источник

- `LESE-FALL_Design_System_Mobile_Tablet_v1_FINAL.md` — отменён (вертикальный скролл).
- Картинки-макеты от ИИ: в них неканонический текст и неправильное деление на слоги.
- Текст внутри любых макетов: только `01_text/` является текстом книги.

## Правила для любого ИИ-агента, работающего с этим репозиторием

1. Текст в `01_text/` не сокращать, не переписывать и не «улучшать».
2. Решения, отмеченные в `DECISIONS.md` как ✅, не пересматривать без явной просьбы.
3. Открытые решения (⏳) не принимать самостоятельно: предложить варианты.
4. Цвета слогов — как в Leseraupe: синий `#1D3F9E`, красный `#E8473A`. Шрифт — локальный Inter из `assets/fonts/` с `font-feature-settings: 'cv05' 1, 'cv11' 1`, никогда не Inter из Google Fonts. Каждое слово начинается с синего, раскрашиваются все слова, включая односложные.
