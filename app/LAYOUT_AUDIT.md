## Было → стало (замеры `befunde.json`)

«Листы < 55 %» — листы чтения (кроме первого с картинкой), заполненные меньше чем на 55 %. «Мин.» — самый пустой лист.

| Прогон | Экраны шире экрана | Кнопки за краем | Листы < 55 % | Мин. заполнение |
|---|---|---|---|---|
| старый 360×740 | 66 → **0** | 32 → **0** | 7 → 2 | 37 % → 46 % |
| старый 360×740 крупный | 84 → **0** | 32 → **0** | 14 → 9 | 15 % → 23 % |
| старый 390×844 | 19 → **0** | 0 | 5 → 2 | 31 % → 43 % |
| старый 412×915 | 0 | 0 | 6 → 1 | 28 % → 48 % |
| новый 360×740 | 70 → **0** | 59 → **0** | 7 → 2 | 34 % → 51 % |
| новый 360×740 крупный | 87 → **0** | 74 → **0** | 11 → 7 | 8 % → 25 % |
| новый 390×844 | 24 → **0** | 0 | 6 → 4 | 11 % → 38 % |
| новый 412×915 | 6 → **0** | 0 | 4 → 1 | 26 % → 52 % |

Оставшиеся полупустые листы — там, где один длинный абзац или «мысль гусенички» не помещается к соседнему (абзацы не делятся, D-06). Дальше улучшить можно только короче абзацами в тексте — это вопрос к переработке текста.

## Замечено, но не трогал (тексты и игры — ждут переработки)

- Лист с одним длинным абзацем при самом крупном шрифте на 360 px может прокручиваться — так задумано (A-13).
- Spur 3, карточки действий на 360 px — 3–4 строки текста, высокие; станет лучше, когда тексты будут короче.
- Spurenwand с одной уликой: много пустых мест на доске — это пустые места для будущих улик (по замыслу).
- Сейф: варианты ответа частично ниже края — лист прокручивается (одна прокрутка, без двойной).
